## Secure Smart Sync Assets

This repository serves as the centralized asset layer for the Secure Smart Sync ecosystem.

It contains logos, icons, screenshots, banners, and other visual assets used across Secure Smart Sync repositories, documentation, websites, and external platforms.

Assets from this repository are served externally through jsDelivr, allowing them to be referenced across README files, documentation pages, websites, release notes, and other public resources without increasing repository size in production repositories.

This repository exists to keep visual assets centralized, reusable, and separate from the main software codebases.
